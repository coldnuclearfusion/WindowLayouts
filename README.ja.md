# WindowLayouts

[English](README.md) · [한국어](README.ko.md) · **日本語** · [中文（简体）](README.zh-Hans.md)

ウィンドウの配置を保存し、メニューバーからワンクリックで元に戻します。

- **保存**：現在のウィンドウの配置を保存します。含めるアプリとウィンドウを選べます。
- **復元**：メニューバーから配置をすぐに適用します。メニューでは、今その位置にある配置にチェックが付きます。配置のウィンドウを 1 つでも移動・サイズ変更・最小化したり閉じたりするとチェックが外れ、元の位置に戻すとまた付きます。
- **手で編集**：設定ウィンドウで各ウィンドウのタイトル・位置・サイズを編集したり、ウィンドウを削除せずに 1 つずつオフにしたりできます。JSON ファイルを直接編集することもできます。
- **モニター構成ごとの配置**：各配置は保存時のモニター構成を記憶します。現在の構成の配置が先に表示され、別の構成で保存した配置を適用すると、今つながっているモニターに合わせてウィンドウを移動します。
- **複数のウィンドウを持つアプリ**：同じアプリの複数のウィンドウは、まずタイトルで、次に順番で対応付けます。
- **起動していないアプリ**：配置に含まれるアプリが起動していないとき、確認する・起動する・起動中のものだけ配置する、のどれにするかを配置ごとに選べます。
- **適用時に最前面へ**：必要に応じて、配置のウィンドウを保存した順に最前面に出します。
- **ブラウザのページ**：ブラウザのウィンドウにページアドレスを持たせられます。適用時はそのページを開いているウィンドウを使い、ページが別のタブの後ろにあっても見つけます（Safari と Chromium 系ブラウザ）。そのタブを前面に出すかどうかは配置ごとに決めます。どのウィンドウにもなければ、新しいウィンドウでページを開きます。
- **Chrome のプロファイル**：Chrome のウィンドウがどのプロファイルのものかを記憶できます。適用時はそのプロファイルのウィンドウだけを使い、必要ならそのプロファイルでウィンドウを開きます。
- **きれいに削除**：一般設定からアプリを削除できます。ログイン時の起動をオフにし、権限項目を削除してから、アプリ、設定、そして残すことを選ばなければ保存した配置もゴミ箱に移します。以前のバージョンの残りを整理するボタンもあります。
- ログイン時に起動してメニューバーに常駐します。Dock アイコンはありません。
- **スクリプトから実行**：`open "windowlayouts://apply?name=Coding"` で、ターミナル、ショートカット、ホットキーアプリから配置を適用できます。
- **言語**：韓国語、英語、日本語、簡体字中国語に対応し、既定ではシステムの言語に従います。一般設定で選択できます。3 つのプラットフォームのアプリが 1 つの文字列テーブル（[`shared/strings.json`](shared/strings.json)）を共有しています。

## プラットフォーム

| プラットフォーム | 状態 | ディレクトリ |
|---|---|---|
| macOS 15 以降 | 利用可能 | [`macos/`](macos/) |
| Windows 10/11 | ドラフト（未ビルド・未テスト） | [`windows/`](windows/) |
| Linux (X11) | ドラフト（未実行・未テスト） | [`linux/`](linux/) |

配置は JSON（`layouts.json`）で保存されるため、プラットフォーム間で同じ形式を使えます。Linux 側のモデルが macOS のファイルを変更なしで読めることは確認済みです。Windows 版と Linux 版は Mac 上で macOS アプリをモジュールごとに移植して書いたもので、まだビルドも実行もしていません。この 2 つは、ウィンドウがその位置にあるかを見張らずに最後に適用した配置にチェックを付けます。また、別のタブの後ろにあるタブの検索、Chrome のプロファイル、アプリの削除はありません。違いは各プラットフォームの README にまとめています。各ディレクトリの文書は英語のみです。

## 言語

UI は韓国語、英語、日本語、簡体字中国語で利用できます。各アプリは既定でシステムの言語に従い（繁体字中国語のシステムでは簡体字中国語）、詳細設定ウィンドウの *一般設定* で言語を固定できます。ユーザーに表示される文字列はすべて [`shared/strings.json`](shared/strings.json) にあります。変わらない識別子をキーとし、`{placeholder}` の置換に対応しています。各プラットフォームはビルド時にこのファイルをコピーします（macOS は `build.sh`、Windows はプロジェクトファイル、Linux は `install.sh`）。言語を追加するには、その言語コードを `languages` とすべての項目に追加してください。

## クイックスタート（macOS）

macOS 15 以降と Xcode が必要です（最近の Command Line Tools には SwiftUI のマクロプラグインがありません。[macos/README.md](macos/README.md)（英語）を参照）。

```bash
git clone https://github.com/coldnuclearfusion/WindowLayouts.git
cd WindowLayouts/macos
./install.sh
```

その後、システム設定 › プライバシーとセキュリティ › アクセシビリティ でアプリを許可してください。再ビルドしても許可が保たれるようにするコード署名、JSON の形式、ブラウザのページと Chrome のプロファイルの扱い、メニューのチェック、問題の調べ方、アプリの削除、複数の Mac へのインストール方法は [`macos/README.md`](macos/README.md)（英語）で詳しく説明しています。
