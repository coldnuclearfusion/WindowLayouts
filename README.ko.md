# WindowLayouts

[English](README.md) · **한국어** · [日本語](README.ja.md) · [中文（简体）](README.zh-Hans.md)

창 배치를 저장해 두고 메뉴 막대에서 한 번의 클릭으로 되돌립니다.

- **저장**: 지금 열려 있는 창들의 배치를 저장합니다. 넣을 앱과 창을 고를 수 있습니다.
- **복원**: 메뉴 막대에서 배치를 바로 적용합니다. 메뉴에는 지금 제자리에 있는 배치에 체크가 표시됩니다. 그 배치의 창을 하나라도 옮기거나, 크기를 바꾸거나, 최소화하거나, 닫으면 체크가 사라지고, 창을 제자리로 돌려놓으면 다시 나타납니다.
- **직접 편집**: 설정 창에서 각 창의 제목, 위치, 크기를 고치고, 창을 지우지 않고 하나씩 끌 수 있습니다. JSON 파일을 직접 편집할 수도 있습니다.
- **모니터 구성별 배치**: 배치마다 저장할 때의 모니터 구성을 기억합니다. 현재 구성의 배치가 먼저 나오고, 다른 구성에서 저장한 배치를 적용하면 지금 연결된 모니터에 맞춰 창을 옮깁니다.
- **창이 여러 개인 앱**: 같은 앱의 여러 창은 제목으로, 그다음 순서로 짝을 맞춥니다.
- **실행 중이 아닌 앱**: 배치에 든 앱이 실행 중이 아닐 때 물어볼지, 실행할지, 실행 중인 것만 배치할지 배치마다 정할 수 있습니다.
- **적용할 때 앞으로 올리기**: 원하면 배치의 창들을 저장된 순서대로 맨 앞으로 올립니다.
- **브라우저 페이지**: 브라우저 창에 페이지 주소를 함께 저장할 수 있습니다. 적용할 때 그 페이지가 열린 창을 찾아 쓰는데, 페이지가 다른 탭 뒤에 숨어 있어도 찾습니다(Safari와 Chrome 계열 브라우저). 찾은 탭을 앞으로 꺼낼지는 배치마다 정합니다. 그 페이지가 열린 창이 없으면 새 창으로 엽니다.
- **Chrome 프로필**: Chrome 창이 어느 프로필의 창인지 기억해 둘 수 있습니다. 적용할 때는 그 프로필의 창만 쓰고, 필요하면 그 프로필로 창을 엽니다.
- **깔끔한 제거**: 일반 설정에서 앱을 제거할 수 있습니다. 로그인 시 실행을 끄고 권한 항목을 지운 뒤, 앱과 설정, 그리고 남기기를 고르지 않았다면 저장한 배치까지 휴지통으로 옮깁니다. 이전 버전이 남긴 흔적을 정리하는 버튼도 따로 있습니다.
- 로그인할 때 자동으로 실행되어 메뉴 막대에 머뭅니다. Dock 아이콘은 없습니다.
- **스크립트로 실행**: `open "windowlayouts://apply?name=Coding"` 으로 터미널, 단축어, 단축키 앱에서 배치를 적용할 수 있습니다.
- **언어**: 한국어, 영어, 일본어, 중국어 간체를 지원합니다. 기본으로 시스템 언어를 따르고 일반 설정에서 바꿀 수 있습니다. 세 플랫폼의 앱이 문자열 표 하나([`shared/strings.json`](shared/strings.json))를 함께 씁니다.

## 플랫폼

| 플랫폼 | 상태 | 디렉터리 |
|---|---|---|
| macOS 15 이상 | 사용 가능 | [`macos/`](macos/) |
| Windows 10/11 | 초안, 아직 빌드·테스트하지 않음 | [`windows/`](windows/) |
| Linux (X11) | 초안, 아직 실행·테스트하지 않음 | [`linux/`](linux/) |

배치는 JSON(`layouts.json`)으로 저장되므로 여러 플랫폼이 같은 형식을 쓸 수 있습니다. Linux 쪽 모델이 macOS 파일을 고치지 않고 그대로 읽는 것은 확인했습니다. Windows와 Linux 버전은 Mac에서 macOS 앱을 모듈 단위로 옮겨 작성했으며, 아직 빌드하거나 실행해 보지 않았습니다. 두 버전은 창이 제자리에 있는지 지켜보지 않고 마지막으로 적용한 배치에 체크를 표시하며, 다른 탭 뒤에 숨은 탭 찾기, Chrome 프로필, 앱 제거 기능이 없습니다. 차이점은 각 플랫폼의 README에 정리되어 있습니다. 각 디렉터리의 문서는 영어로만 되어 있습니다.

## 언어

UI는 한국어, 영어, 일본어, 중국어 간체로 제공됩니다. 각 앱은 기본으로 시스템 언어를 따르고(중국어 번체 시스템에서는 간체로 표시), 상세 설정 창의 *일반 설정*에서 언어를 고정할 수 있습니다. 사용자에게 보이는 문자열은 모두 [`shared/strings.json`](shared/strings.json)에 있습니다. 바뀌지 않는 식별자를 키로 쓰고 `{placeholder}` 치환을 지원하며, 각 플랫폼은 빌드할 때 이 파일을 복사해 넣습니다(macOS는 `build.sh`, Windows는 프로젝트 파일, Linux는 `install.sh`). 언어를 추가하려면 `languages`와 모든 항목에 그 언어 코드를 추가하세요.

## 빠른 시작 (macOS)

macOS 15 이상과 Xcode가 필요합니다(최근 Command Line Tools에는 SwiftUI 매크로 플러그인이 없습니다. [macos/README.md](macos/README.md)(영어) 참고).

```bash
git clone https://github.com/coldnuclearfusion/WindowLayouts.git
cd WindowLayouts/macos
./install.sh
```

그다음 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 앱을 허용하세요. 다시 빌드해도 권한이 유지되게 하는 코드 서명, JSON 형식, 브라우저 페이지와 Chrome 프로필 처리, 메뉴의 체크 표시, 문제 진단 방법, 앱 제거, 여러 Mac에 설치하는 방법은 [`macos/README.md`](macos/README.md)(영어)에 자세히 있습니다.
